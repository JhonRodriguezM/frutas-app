# ¿Qué fruta es más parecida? — Sesión 2

App de Streamlit de la sesión 2 de **Computación Avanzada** (Vectores y matrices).
Cada fruta se representa como un vector `[peso, diámetro, dulzor]` y se compara con
la fruta que ingresa el usuario usando la distancia euclidiana.

Actividad de clase: se agregó la **pera** `[180 g, 6.5 cm, 6]` y la app muestra el
cálculo de la distancia entre la fruta ingresada y la pera.

```bash
pip install -r requirements.txt
streamlit run frutas_app.py
```
